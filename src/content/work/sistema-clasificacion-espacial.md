# Sistema Algorítmico de Clasificación Espacial para Tejidos Urbanos

## Contexto
El crecimiento urbano contemporáneo suele generar fracturas morfológicas difíciles de catalogar mediante herramientas analíticas convencionales. Este proyecto desarrolla un sistema para mapear continuidades y discontinuidades espaciales.

## Metodología
Utilizando representaciones de redes axiales y grafos espaciales acoplados a modelos de aprendizaje automático, analizamos la accesibilidad y densidad de integración visual en sectores residenciales consolidados y áreas periurbanas.

## Hallazgos Clave
- La integración de Space Syntax con modelos de lenguaje permite traducir métricas de grafos en diagnósticos urbanos legibles para no especialistas.
- Se optimiza el tiempo de diagnóstico previo en estudios de impacto ambiental y planes directores.
